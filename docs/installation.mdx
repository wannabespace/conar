## Desktop

[Download Tamery](https://tamery.app/download) for macOS, Windows, or Linux. Use desktop for local databases, SQLite and DuckDB files, SSH tunnels, and [MCP](/mcp/overview).

- **macOS:** open the `.dmg` and drag Tamery to **Applications**. Or install with Homebrew:

  ```bash
  brew install --cask tamery
  ```

- **Windows:** run the `.exe` installer.
- **Linux:** choose the `.deb`, `.rpm`, or AppImage download. On Arch, install `tamery-bin` from the AUR and launch `tamery-app`.

Tamery is in early access. Sign in with email, Google, or GitHub to join the list. We email you when your account is ready.

## Web

Open [tamery.app](https://tamery.app) and sign in. Public database servers work without installing anything.

For localhost, private networks, or SQLite and DuckDB files, keep the [local proxy](/cli/commands#tamery-proxy) running on the computer that can reach them. SSH tunnels require desktop.

## CLI

Requires **Node.js 22.16 or later**.

```bash
npm install -g tamery
tamery login
```

See [CLI commands](/cli/commands) to run SQL or start the local proxy.
