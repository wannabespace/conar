## Desktop

[Download Tamery](https://tamery.app/download) for macOS, Windows, or Linux. Use desktop for local databases, SQLite files, SSH tunnels, and [MCP](/mcp/overview).

- **macOS:** open the `.dmg` and drag Tamery to **Applications**. Or install with Homebrew:

  ```bash
  brew install --cask tamery
  ```

- **Windows:** run the `.exe` installer.
- **Linux:** choose the `.deb`, `.rpm`, or AppImage download. On Arch, install `tamery-bin` from the AUR and launch `tamery-app`.

## Web

Open [tamery.app](https://tamery.app) and sign in. Public database servers work without installing anything.

For localhost, private networks, or SQLite files, keep the [local proxy](/cli/commands#tamery-proxy) running on the computer that can reach them. SSH tunnels require desktop.

## CLI

Install it with npm (Node.js 22.16 or later). See [Tamery CLI](/cli/overview).
