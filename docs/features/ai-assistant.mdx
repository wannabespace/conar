Open the chat button in the tab bar, or press **Cmd+L** on macOS, **Ctrl+L** on Windows or Linux. Paste a query, an error, or a table definition and ask for help.

Try:

- “Explain this query.”
- “Why does this SQL fail?”
- “Write a monthly sales query using these tables.”

Follow up in the same conversation to refine the answer. Use **New chat** to start over.

## Give it context

The chat uses what you send it. It does not automatically read your schema, query your data, or make changes. Include the relevant table and column names, then review and run suggested SQL yourself.

Messages are processed by external AI providers. See [Security and privacy](/connections/security#ai-and-your-data).

## AI elsewhere in Tamery

- **Table filters:** describe the rows you want and choose **Ask AI**.
- **SQL editor:** use **Edit with AI**, **Fix with AI**, or accept a completion with **Tab**. These features receive schema context automatically.
- **Connection errors:** choose **Explain with AI** after a failed test.

The assistant and SQL help require [Pro](/account/plans). Free accounts include limited AI filters and connection diagnosis. Tamery chooses the model automatically.

To let a coding agent inspect tables and run SQL, connect it through [MCP](/mcp/overview).
