The assistant has full context of your connected database — schemas, tables, column types, relationships — so it writes accurate SQL without you pasting schema into every message. It lives in its own panel beside whatever you have open, and it can act on the app: opening tables, filling a SQL runner, applying filters.

## Opening the panel

Click the **sparkle** icon at the end of the tab strip, or press <kbd>⌘</kbd> <kbd>L</kbd> (<kbd>Ctrl</kbd> <kbd>L</kbd> on Windows and Linux). Drag the panel's left edge to resize it; double-click that edge to reset the width.

The panel belongs to the connection, not to a tab — it stays open while you move between tables, runners, the schema browser, and the diagram. Each connection keeps its own chats; use **＋** for a new one and the **history** icon to reopen an earlier one.

## Asking

Ask in plain English:

- _"Which tables store customer order data?"_
- _"Explain this query and whether it can be optimized."_
- _"Find users who signed up in the last 7 days but haven't ordered."_

Follow-ups like _"now only EU users"_ work — the conversation keeps its context.

## Approving changes

Reads run on their own. Anything that changes data or schema — `INSERT`, `UPDATE`, `DELETE`, `CREATE INDEX`, `RENAME`, `DROP` — stops and shows you a card with the exact statement, the assistant's reason, and a warning when a write has no filter and would touch every row. Nothing runs until you choose **Run it**.

<Note>
  Your credentials never leave your device: the assistant's database tools run
  in the app, against your connection, exactly like a query you type yourself.
</Note>

## Models

The assistant runs on a frontier model automatically — nothing to pick or configure. If the primary model is overloaded, Tamery falls back to another top model to stay responsive.

## Enhance prompt

Click **Enhance** before sending to rewrite a vague message into a clearer one, with schema context added. You review the result before it's sent.

## Natural-language filters

<Steps>
  <Step title="Focus the filter field">
    In the table browser, click the filter field in the bottom toolbar or press
    <kbd>⌘</kbd> <kbd>F</kbd>.
  </Step>
  <Step title="Describe the filter">
    Type, e.g. *"orders in the last 30 days over $500 that haven't shipped"*,
    then choose **Ask AI**.
  </Step>
  <Step title="Review and adjust">
    The AI builds structured filter chips in the field. Edit any chip's column,
    operator, or value directly.
  </Step>
</Steps>

<Note>
  Free accounts get a limited number of AI filter uses per month. Paid plans are
  unlimited. See [Plans](/account/plans).
</Note>

## AI data seeding

Open a table, click **Seed**, set a row count. Tamery picks generators from column names and types — names, emails, timestamps, and foreign keys referencing existing rows. Rows are previewed before insertion.
