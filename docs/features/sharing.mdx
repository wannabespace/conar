A share is a link like `share.tamery.app/…` that shows one table's rows to anyone who opens it, without a Tamery account. Viewers see it the way the table looks in Tamery: they can sort by a column and scroll to load more rows. They cannot edit anything.

## Share a table

Sharing needs a connection synced with **Full** (see [Security](/connections/security)), since Tamery's servers read the rows from your database each time the link refreshes.

1. Open the table and set it up the way you want it seen: filters, hidden columns, column order and sort.
2. Click the share button in the table toolbar.
3. Enter a name and an optional description.
4. Click **Share**. The link is copied.

Before saving, Tamery checks that its servers can reach the database. A database on `localhost`, on a private network, behind a VPN or in a SQLite file can't be shared, and the dialog says why.

The share shows the columns the table shows, in the same order. With filters on, **Apply the table's filters** decides whether viewers see only the matching rows.

| Option | What it does |
| --- | --- |
| **Refresh** | How long viewers see the same rows before Tamery reads them again: **Live**, **Every minute**, **Every hour** or **Every day**. |
| **Expires** | The link stops working after 1, 7 or 30 days, or never. |
| **Require a password** | Viewers enter the password once to open the link. |

## Change or stop sharing

Click the share button again to copy the link or change the share. **Save changes** also takes the table's current filters and columns.

**Manage shares** in the dialog opens **Settings** > **Shares**, which lists every shared table. A share whose rows stopped loading for viewers is marked there. Click **Stop sharing** to turn a link off for everyone. Sharing the table again makes a new link.

Deleting a connection stops sharing its tables.

## Limits

The Free plan shares up to 3 tables at a time; [Pro](/account/plans) has no limit.
