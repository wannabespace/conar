---
title: 'Table browser'
description: 'Filter, sort and edit rows without writing SQL. Edits stay drafts until you save them.'
---

Open a connection and choose a table in the Navigator. Click to preview it. Double-click to keep its tab open.

## Find the rows you need

- **Filter:** use the filter field to pick a column, operator, and value. Or right-click a cell and choose **Filter by value**.
- **Ask AI:** type something like “unpaid orders from last week” and choose **Ask AI**. Review the filters it creates.
- **Sort:** click a column header for ascending, descending, then off. Shift-click another column to add a sort level.
- **Follow relationships:** click the arrow on a related cell to peek at its record or the rows that reference it. **Open in Table** opens those rows in a tab.

Filters, sorting, column order, and widths are remembered per table.

## Edit rows

1. Double-click a cell or press **Enter** to edit it.
2. Change the value and press **Enter**. The edit stays as a draft.
3. Use **Review** to check your edits, then **Save** to write them to the database. **Discard** cancels them.

Use the toolbar's **+ → Add row** for a new row, or right-click a cell and choose **Duplicate Row**. A new row shows **Discard row** where the checkbox would be, and the same action is **Discard Row** on the cell menu. Select row checkboxes and choose **Delete** to remove saved rows; deletion asks for confirmation.

You can paste a block from a spreadsheet, copy selected cells back to it, and undo draft edits with **Cmd/Ctrl+Z**. A primary key is required to add or edit rows; generated columns are read-only.

Changing filters or sorting clears staged cell edits. Save them first; undo can restore them.

## Choose how data looks

Switch to **Documents** view to read one record at a time, with expandable JSON. In the grid, resize or reorder columns by dragging, or use a column's menu to hide or pin it.

The column menu also offers **Distinct Values** to inspect common values, and **Show Labels** to display a related name beside a foreign key.

A time stored with a time zone other than yours shows the stored value, then your local time.

## Change the structure

Use **+** to add a column. Right-click a column to edit it, or a table in the Navigator to rename or drop it. Schema menus let you create tables and views. Available actions depend on the database engine.

For changes across several tables, use the [schema visualizer](/features/schema-visualizer).

## Generate test data

Choose **⋯ → Seed data**, review the generator for each column, choose a row count, and insert. This writes new rows to your database. Free usage is limited; [Pro](/account/plans) removes the limit.

For keyboard shortcuts, open **Settings → Keyboard**.
