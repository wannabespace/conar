Open **Schema → Visualizer** in the Navigator.

Each card is a table or view. Lines connect foreign keys to the keys they reference. Click a card to inspect its columns and relationships.

## Explore

Drag the background to pan, zoom to see more or less detail, and search with **Cmd/Ctrl+F** to find a table or column. Drag tables to arrange them; Tamery remembers their positions.

## Make changes

- Use **+ Table** to create a table.
- Right-click a table to rename it, add a column, or drop it.
- Right-click a column to edit or drop it.
- Drag a column's edge handle onto a primary or unique key to add a foreign key.
- Select a relationship and press **Delete** to remove it.

The available actions depend on your database engine. Views are read-only in the diagram.

## Review and apply

Changes stay as drafts until you click **Apply**. Use the review button to inspect the exact SQL and discard individual changes. Dropping an object opens the review before applying.

PostgreSQL, SQL Server, and SQLite apply the changes in one transaction. MySQL, Oracle, and ClickHouse apply schema changes separately, so an error can leave some changes already applied. Review the remaining drafts before retrying.
