## 1. Open Tamery

[Download the desktop app](https://tamery.app/download) or [open the web app](https://tamery.app).

Sign in with email, Google, or GitHub. Tamery is in early access: if your email has not been approved yet, signing in joins the list. We email you when you can start.

## 2. Add a connection

Click **Add new** and paste your connection string. You can also paste an `.env` file or fill in the fields yourself.

```text
postgresql://user:password@localhost:5432/mydb
```

Give it a name and click **Save connection**. Tamery tests it before saving. If it fails, check the highlighted fields or try **Explain with AI**.

For a local database, use the desktop app or run [`tamery proxy`](/cli/commands#tamery-proxy) alongside the web app.

## 3. Explore

Open the connection and pick a table in the Navigator. Click a column header to sort; use the filter field to narrow the rows.

To run SQL, open a **Query** tab with **+** and try:

```sql
SELECT 1 AS hello;
```

Click **Run** or press **Cmd+Enter** on macOS, **Ctrl+Enter** on Windows or Linux.

From here, [edit table data](/features/table-browser), [explore the schema](/features/schema-visualizer), or [ask the AI assistant](/features/ai-assistant).
