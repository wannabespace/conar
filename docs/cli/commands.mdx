Use `tamery --help` or `tamery <command> --help` for help in your terminal.

## tamery login

```bash
tamery login
```

Opens browser sign-in and saves your session locally.

| Flag | Use |
| --- | --- |
| `--no-open` | Print the sign-in URL instead of opening a browser. |
| `--force`, `-f` | Sign in again, for example to switch accounts. |

## tamery logout

```bash
tamery logout
```

Clears your local CLI session.

## tamery whoami

```bash
tamery whoami
```

Shows which account is signed in.

## tamery query

Run SQL against a connection saved in the app:

```bash
tamery query --list-connections
tamery query -c my-db "SELECT 1 AS hello"
tamery query -c my-db --file ./report.sql
tamery query -c my-db --json "SELECT 1 AS hello"
```

| Flag | Use |
| --- | --- |
| `--connection`, `-c` | Connection name or ID. Required when you have more than one; use the ID if names repeat. |
| `--file`, `-f` | Read SQL from a file. |
| `--json` | Display result rows as JSON. |
| `--list-connections` | List saved connections and exit. |

The CLI needs a synced connection string with the secrets required to connect. **Metadata only** connections cannot be used, and **No password** connections do not supply the saved password. SSH tunnels require desktop. SQLite paths refer to files on the computer running the command.

SQL runs against the database, including writes. The CLI does not show the app's confirmation dialogs.

## tamery proxy

```bash
tamery proxy
```

Lets the web app reach localhost, private networks, and SQLite files through this computer. Sign in to the same account in the CLI and browser; the web app detects the proxy automatically.

Database queries go through your machine. The proxy still needs internet to verify your Tamery session. Stop it with **Ctrl+C**.
