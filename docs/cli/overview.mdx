## Install and sign in

Requires **Node.js 22.16 or later**.

```bash
npm install -g tamery
tamery login
```

Finish signing in in the browser. Use the same account as the app.

## Run a query

Create a connection in Tamery first, then find its name:

```bash
tamery query --list-connections
tamery query -c my-db "SELECT 1 AS hello"
```

You can also run SQL files or request JSON output. See [all commands](/cli/commands).

## Reach local databases from the web

```bash
tamery proxy
```

Keep this running on the computer that can reach the database. The web app detects it automatically. Stop it with **Ctrl+C**.

The proxy also opens SQLite and DuckDB files on that computer. SSH tunnels require the desktop app.
