Choose **SQL Server** under **Engine**, or paste:

```text
sqlserver://user:password@localhost:1433/mydb
```

`mssql://` works too. The default port is **1433**. You can also paste a JDBC or ADO.NET connection string.

## Azure SQL

Use the hostname and database from your Azure connection details:

```text
sqlserver://user:password@your-server.database.windows.net:1433/mydb?encrypt=true&trustServerCertificate=false
```

Allow your IP address in the server's firewall settings.

## Encryption

| Option | Behavior |
| --- | --- |
| `encrypt=true` | Encrypt the connection. |
| `trustServerCertificate=false` | Verify the server's certificate. |
| `trustServerCertificate=true` | Skip certificate verification. |

For a local development server with a self-signed certificate:

```text
mssql://sa:password@localhost:1433/mydb?encrypt=true&trustServerCertificate=true
```

For localhost in the web app, run the [local proxy](/cli/commands#tamery-proxy).
