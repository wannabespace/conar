## Add a connection

Click **Add new**. Paste a connection string, `.env` contents, JDBC URL, database command, or SQLite file path. Tamery fills in the fields; you can also enter them yourself.

Choose an engine, check the details, and give the connection a name. Click **Save connection** or press **Enter** in a text field.

On desktop, you can also:

- Pick a detected Docker database or a connection from another database client.
- Drop a config or SQLite file onto the window.
- Use **Add via MCP** to have your coding agent add a connection from your project.

## Choose what syncs

| Sync type | On another device |
| --- | --- |
| **Full** | Open the connection without re-entering its password. The full connection string is stored encrypted in the cloud. |
| **No password** | Enter the password and any SSH or SSL key secrets on each device. The remaining connection details sync. |
| **Metadata only** | Enter the server details on each device. Only the connection's name, engine, label, and color sync. |

Choose this when you create the connection. To use a different sync type later, add it as a new connection. See [Security](/connections/security) for details.

## Local and private databases

The desktop app connects directly. In the web app, run [`tamery proxy`](/cli/commands#tamery-proxy) on a computer that can reach the database.

For an SSH bastion, turn on **SSH tunnel** in the connection form. Use your SSH agent, a key file, a pasted key, or a password. SSH tunnels work on desktop only.

## If the test fails

Tamery points to common causes and offers fixes where possible. Check the host, port, password, SSL settings, and your provider's allowed IP addresses.

**Explain with AI** can help with an unfamiliar error. **Save anyway** saves a connection you cannot reach yet.

## Keep connections organized

Give each connection a label and color, pin the ones you use often, or group them in [workspaces](/features/workspaces).

To change a connection, right-click it and choose **Edit**. **Save changes** tests the new details before saving.

## Offline

On desktop, you can query databases you can still reach without internet. Changes to connections and saved queries sync when you reconnect. Signing in, creating a workspace, and AI features need internet; so do queries in the web app.
