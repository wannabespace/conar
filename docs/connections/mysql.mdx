Choose **MySQL** or **MariaDB** under **Engine**, or paste a connection string:

```text
mysql://user:password@localhost:3306/mydb
```

```text
mariadb://user:password@localhost:3306/mydb
```

The default port is **3306**. An `.env` file or a `mysql` / `mariadb` command works too.

## SSL

Use your provider's connection string with its SSL options. To require encryption and verify the certificate:

```text
mysql://user:password@db.example.com:3306/mydb?ssl=true&sslrejectunauthorized=true
```

With no SSL option, Tamery tries an encrypted connection without certificate verification. It uses an unencrypted connection only if the server reports that SSL is unavailable. `ssl=false` turns encryption off explicitly.

## MariaDB

You can browse and edit rows, run SQL, and manage the schema as with MySQL. System-versioned tables show current rows; query their history with SQL. Sequences are available through SQL rather than the Navigator.

For localhost in the web app, run the [local proxy](/cli/commands#tamery-proxy).
