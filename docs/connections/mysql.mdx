Tamery supports MySQL and MariaDB via the `mysql://` scheme:

```bash
mysql://username:password@hostname:3306/database
```

| Part       | Description                                 |
| ---------- | ------------------------------------------- |
| `username` | MySQL user (e.g. `root`)                    |
| `password` | Password for that user                      |
| `hostname` | Host (e.g. `localhost` or a remote address) |
| `3306`     | Port (default)                              |
| `database` | Database name                               |

## SSL / TLS

Enable SSL with query parameters:

```bash
mysql://username:password@hostname:3306/database?ssl=true
```

To reject untrusted certificates, add `sslrejectunauthorized=true`:

```bash
mysql://username:password@hostname:3306/database?ssl=true&sslrejectunauthorized=true
```

Check your provider's docs for the exact parameters they require.

## Providers

<Tabs>
  <Tab title="PlanetScale">
    Dashboard → database/branch → **Connect**. PlanetScale requires SSL.

    ```bash
    mysql://username:password@aws.connect.psdb.cloud/your-database?sslaccept=strict
    ```

  </Tab>
  <Tab title="Railway">
    Project → MySQL service → **Connect** → **Database URL**.

    ```bash
    mysql://root:password@monorail.proxy.rlwy.net:12345/railway
    ```

  </Tab>
  <Tab title="Local">
    ```bash
    mysql://root:password@localhost:3306/mydb
    ```

    No password? Omit it:

    ```bash
    mysql://root@localhost:3306/mydb
    ```

  </Tab>
</Tabs>

## MariaDB

Pick **MariaDB** under **Engine**, or paste a `mariadb://` string, a `mariadb` command or a `MARIADB_*` environment (including Laravel's `DB_CONNECTION=mariadb`) and Tamery picks it for you. The connection shows the MariaDB name and icon and runs on the MySQL driver, so everything above applies:

```bash
mariadb://username:password@hostname:3306/database
```

Where MariaDB differs from MySQL:

- **JSON columns** are `LONGTEXT` with a `json_valid()` check in MariaDB. Tamery still reads them as JSON, so you edit their cells as JSON.
- **System-versioned tables** list in the Navigator with your other tables and show their current rows. Query their history with `FOR SYSTEM_TIME` in a **Query** tab.
- **`UUID` cells** tell you when what you typed isn't a UUID, before it reaches the database.
- **Data seeding** fills `INET4` and `INET6` columns with IP addresses.
- **Sequences** don't list in the Navigator. Read and advance them with `NEXTVAL()` and `SHOW CREATE SEQUENCE` in a **Query** tab.

<Note>
  MySQL `SET` columns show as **Enums** in the Schema list. Display only — your
  data and schema are unaffected.
</Note>

<Tip>
  **Save connection** tests the connection first. If the test fails, check host,
  port, credentials, and SSL parameters.
</Tip>
