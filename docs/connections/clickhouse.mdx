Tamery uses ClickHouse's **HTTP interface**. Paste its HTTP or HTTPS connection string into **Add new**.

## ClickHouse Cloud

Copy the HTTPS connection details from your service's **Connect** panel:

```text
https://default:password@your-service.clickhouse.cloud:8443/default
```

## Local server

```text
http://default:password@localhost:8123/default
```

Omit `:password` if the user has no password.

Use port **8123** for HTTP or **8443** for HTTPS. The native TCP ports, **9000** and **9440**, are not used by Tamery.

When you enter a host manually, Tamery uses HTTPS unless you choose port 8123.

## Differences to know

ClickHouse does not support transactions. Schema changes apply one at a time, and existing sorting-key values cannot be edited in the table browser.

For localhost in the web app, run the [local proxy](/cli/commands#tamery-proxy).
