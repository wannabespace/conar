Tamery's desktop app includes an MCP server. Your coding agent can inspect tables and run SQL through your saved connections, without putting connection strings in its config.

## Connect an agent

1. Open **Settings → MCP** in the desktop app.
2. Check that **Run MCP server** is on.
3. Choose your client and copy its command or configuration.
4. Add it to your client, then ask: “List my Tamery connections.”

Setup is available for Claude Code, Codex, Cursor, VS Code, Gemini CLI, and Windsurf. Keep a signed-in Tamery window open while using the agent.

With **Keep running in the background** on, Tamery prevents closing the app and keeps the server running. On a Mac, once an agent has connected, press <kbd>⌘</kbd> <kbd>Q</kbd> again or quit from the Dock to stop it.

Other clients can use Streamable HTTP at `http://127.0.0.1:26381/mcp` with an `Authorization: Bearer <token>` header. Copy the token from **Settings → MCP**.

## Connection access

In **Settings → MCP → Connection access**, choose what agents can do for each connection:

| Access | What it allows |
| --- | --- |
| **Not shared** | The agent cannot see or use the connection. |
| **Read only** | Read data and schema. |
| **Ask before writing** | Read freely; approve each write in Tamery. This is the default. |
| **Read and write** | Read and change data or schema without asking. |

Access settings apply on this device. For database-enforced read-only access, use a database user with read-only permissions; Tamery's checks cannot prevent every function side effect.

## Approving a write

With **Ask before writing**, Tamery shows the SQL before it runs. Choose **Run** to apply it or **Decline** to refuse. A notification tells you when an agent is waiting.

Check the statement carefully, especially its `WHERE` clause. Any row-count estimate is approximate.

## Available tools

| Tool | Purpose |
| --- | --- |
| `list_connections` | Find shared connections and their databases. |
| `create_connection` | Test and save a new connection. SQLite files and SSH connections must be added in Tamery instead. |
| `list_tables` | List tables and views. |
| `describe_table` | Inspect columns, keys, and indexes. |
| `query` | Read data, returning up to 200 rows. |
| `execute` | Change data or schema, subject to connection access. |

Try “Describe the orders table” or “Find duplicate customer emails.” Results returned to your agent become part of that client's AI context.

## Limits and security

Free accounts include **100 queries or writes per week**, resetting Monday at 00:00 UTC. Listing connections and inspecting schema do not count. [Pro](/account/plans) removes the limit.

**Settings → MCP** also shows connected clients and recent activity. The local activity log includes SQL statements, so avoid putting secrets in queries.

Keep the access token private. **Regenerate** replaces it and disconnects clients using the old token. Reconfigure the clients you want to keep.
