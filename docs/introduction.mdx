Tamery is a database client for PostgreSQL, MySQL, MariaDB, SQL Server, ClickHouse, and SQLite, including Turso and Cloudflare D1.

Use it on [macOS, Windows, or Linux](/installation), or [in your browser](https://tamery.app).

## What you can do

| Task | Where to go |
| --- | --- |
| Find, filter, and edit rows without SQL | [Table browser](/features/table-browser) |
| Write SQL, inspect results, and save queries | [SQL editor](/features/sql-editor) |
| See how tables connect and change their structure | [Schema visualizer](/features/schema-visualizer) |
| Manage indexes, constraints, functions, and more | [Schema](/features/definitions) |
| Get SQL explanations, edits, and error fixes | [AI assistant](/features/ai-assistant) |
| Send anyone a read-only link to a table | [Sharing tables](/features/sharing) |
| Let your coding agent use your connections | [MCP](/mcp/overview) |
| Run queries from your terminal | [CLI](/cli/overview) |

Your connections sync across devices. You choose whether passwords sync too.
