# Kit gotchas

- `CommandDialog` is only a Dialog shell — wrap contents in `<Command>` or cmdk crashes.
- `CommandItem` appends a hidden `ml-auto` check — right-aligned meta goes in `CommandShortcut` (also hides the check). Explicit `value` on items that can mount mid-search.
- `PopoverContent` defaults `flex flex-col gap-4 p-4 w-72` — menu-like popovers need `gap-0 p-1`, often `w-auto`.
- `DropdownMenuLabel` requires a `DropdownMenuGroup` parent (base-ui throws).
- base-ui render prop: `<Trigger render={<Button/>}>children</Trigger>` — children land inside. Non-button trigger needs `nativeButton={false}` + `aria-label`.
- `InputGroup` addon sizes direct-child svgs only — nested icons need explicit `size-4`.
- Base Button has an `active:translate-y-px` press dip that **replaces** any layout transform — never center a button with `absolute` + `-translate-y-1/2` (it jumps on press); use `inset-y-0 my-auto` or in-flow flex.
- Router `Link` concatenates `activeProps.className` (no tw-merge) — use `data-[status=active]:` variants in one className.
- CSS transitions can't interpolate length↔percentage — keep both endpoints in rem.
- Selects: macOS overlay mode (`alignItemWithTrigger`) + `min-w-(--anchor-width)`; never fix-width a trigger narrower than its longest option; `size` goes on trigger AND content.
- Hotkeys: always `e.preventDefault()`; `getOS(navigator.userAgent)` for ⌘ vs Ctrl labels.
- Scroll-edge fades must never cover the scrollbar: masks clip it, overlay siblings paint over it — the data table puts gradients inside the scroller as sticky zero-height anchors (`table-fade*`); shadcn `scroll-fade` (mask) only with `no-scrollbar`.
- cmdk 1.1.1 group filtering is broken (groups never reorder by score) — the actions center bypasses with `shouldFilter={false}` + its own scoring via cmdk's `defaultFilter`.
- Electron `Menu.popup`'s item-`click` can fire AFTER the close callback — resolve on click immediately, settle null on a 150ms delay. Platform branch lives in `AppContextMenu` in `apps/app`; `packages/ui` stays electron-agnostic.
- `motion.create(X)` belongs in its own `x.motion.tsx`, never `x.utils.ts` — creates an import cycle that throws a TDZ error. `.utils.ts` stays value-free.
- An `absolute` wrapper is `display: block`, so an inline-level child sits on the text baseline ~2-3px off center — give the wrapper `flex items-center justify-center`.
- base-ui `Menu.Item` closes the menu on click — in-menu toggles need `closeOnClick={false}`.
- **Monaco view zones render in a detached React root** — no context of any kind crosses (router, query client, stores). Zone components take everything as props / module-level stores and pass `queryClient` explicitly; swapping a prop for a context hook typechecks, then throws at mount.
- **`Reorder.Group` values must be stable primitives** — it keys layout by `value` identity, so recreated objects re-measure everything and the strip twitches. Pass ids; set `axis` explicitly.
- Streamdown needs `@source "../../node_modules/streamdown/dist/*.js"` in globals or it renders unstyled; overriding `components.pre` replaces its code block entirely (that's how kit `CodeBlock` takes over — a partial override makes nested cards).
- Shiki dark theme needs the one `!important` rule in globals (`.dark [data-slot='code-block'] span[style*='--shiki-dark']`) — the light color ships inline, so dark mode otherwise renders github-light and identifiers go invisible.
- **`animate-none` does not reliably cancel `animate-in`/`animate-out`** (Tailwind's own utility ordering wins) — make animation classes conditional instead (`animated` prop on Dialog pieces; `CommandDialog` passes `animated={false}`).
- A focusable control inside a `CommandItem` steals the keyboard's place — give it `tabIndex={-1}` + `preventDefault` on pointerdown; refocus `CommandInput` in `onSelect`.
- **A width-animated panel must have its content state ready on the opening frame** — mint the content's key synchronously in the interaction that opens it, not in a mount effect (content pops in mid-animation otherwise). Don't gate mounting on collection `isReady` (shipped and reverted); never block first paint on the network.
- Enter-to-submit fields must guard IME composition (`!event.nativeEvent.isComposing`) or CJK input submits half-composed.
- A `render={<Button/>}` wrapper that hard-codes surface classes makes the `variant` prop a lie — wrapper classes own position/animation/shape; the surface belongs to the variant.
- Desktop kills text selection app-wide (`.electron body` `select-none`, opt-back-in by element type only) — any component whose job is displaying readable prose needs `select-text` (kit `MessageContent` carries it). Repro in browser by adding the `electron` class manually.
- `content-visibility: auto` breaks a scroller's scroll math (skipped items measure as estimates) — use real virtualization instead.
- **`scrollAnchor` must never mark every user turn** — the anchor pass also fires on an equal-count child mutation and scrolls to the first unhandled anchor (the oldest message). The chat anchors only turns this tab sent, and only safely because the transcript strictly appends — the pending spinner renders inside the last item, never as its own item.
- A 1px line can't be centered in an even gutter with whole-pixel padding — center with layout (`flex justify-center` in a symmetric span), not padding.
- `@tamery/table` column renderers are render props, not component types — `header.tsx`/`body.tsx` *call* them (`column.header({…})`); rendering `<column.header/>` remounts the cell subtree every parent render and kills local cell state (broke the resize handle mid-drag).
