# Motion

- `motion` library for interruptible animation, not CSS transitions (transitions snap under frame drops). Exception: pure color/opacity hovers — `transition-colors` fine.
- House curve `[0.32, 0.72, 0, 1]`, 150–300ms. Collapse via width/transform; no whole-panel opacity fades. `AnimatePresence` for mount/exit of conditional chrome. No layout shifts on hover — reserve space, animate opacity/transform only.
- **Anything keyed to the highlighted row of a keyboard list has no transition** — highlight jumps a row per keystroke; a fade smears indicators down the list. Hover-only reveals inside one row may still fade.
- **Virtualized reorder** (tables tree): motion `layout` can't work with tanstack-virtual — stable `getItemKey` + `motion.li` `initial={false} animate={{ y: virtualRow.start }}`. Rows sliding to new `y` *is* the collapse animation; tween `{ duration: 0 }` while search filters (churn per keystroke reads as noise). Ref: `navigator/tables-list.tsx`.
- **Pane folds** (navigator, chat, query logger, runner results, logger detail): kit `ResizablePanel collapsed={…}` — the one place a CSS transition animates layout. `react-resizable-panels` owns every size as inline `flex-grow`, so `motion` cannot drive it; the kit writes the house-curve transition (250ms) as **inline `style.transition`** on the group's children for the fold only, so window resizes never animate — an attribute gate would recalc the whole subtree ([gotchas.md](gotchas.md)). Content stays mounted at size 0 behind a pinned-size child; a collapsed, settled panel clips so parked content never peeks into the window padding.
- **Collapse/disclosure**: animate CSS grid rows — `animate={{ gridTemplateRows: open ? '1fr' : '0fr' }}` wrapping a `min-h-0 overflow-hidden` child.
- **Swapping two panels in one slot**: `AnimatePresence mode="popLayout"`, opacity + small `x` offset in the push direction, 150–180ms.
- **Reorderable strips**: `Reorder.Group`, `layout="position"`, animate layout only while dragging (snap otherwise — no drift when labels change width). Value identity rules in [gotchas.md](gotchas.md).
- Scroll-edge cues: never JS scroll listeners — `scroll-fade` (CSS mask) for plain scrollers, `table-fade` overlay for the data table (mask would clip the scrollbar; [gotchas.md](gotchas.md)).
- **Popup enter/exit** (all kit menu/popover/select content): tw-animate-css `animate-in/out` + fade/zoom/slide, `data-open:duration-150 data-closed:duration-100` on the house curve — the shipped defaults read as no animation. Exits stay shorter than entries.
- **`DitherBackground` mounts its shader late.** The paper-design `Dithering` shader compiles and starts a continuous render loop on mount, which competes with the sign-in page's entrance animations; the component holds it back ~700ms and fades it in over 1.2s itself. Call sites render `<DitherBackground />` bare — no wrapper fade.
