# Motion

- `motion` library for interruptible animation, not CSS transitions (transitions snap under frame drops). Exception: pure color/opacity hovers — Tailwind `transition-colors` fine.
- House curve `[0.32, 0.72, 0, 1]`, 150–300ms. Collapse via width/transform; no whole-panel opacity fades.
- `AnimatePresence` for mount/exit of conditional chrome.
- No layout shifts on hover — reserve space, animate opacity/transform only.
- **Anything keyed to the highlighted row of a keyboard list has no transition** — `group-data-selected/command-item:opacity-100` affordances must snap: highlight jumps a whole row per keystroke; a 150ms fade smears indicators down the list when holding arrow. Hover-only reveals inside a single row may still fade. (Sort popover's ↑-on-highlight hint later deleted outright — the group heading already says these rows add a sort.) Ref: `toolbar/actions/actions-order.tsx`.
- **Virtualized reorder** (tables tree pin): motion `layout` can't work with tanstack-virtual — stable `getItemKey` (row id, not index) + `motion.li` with `initial={false} animate={{ y: virtualRow.start }}`. `y` changes only on reorder or schema collapse/expand, never during scroll. Surviving rows sliding to new `y` **is** the collapse/expand animation — folded rows unmount instantly (no `AnimatePresence` inside a virtualizer), acceptable; an earlier `isSchemaToggling` rAF flag zeroing the tween during toggles was removed as not worth the hack. `y` tween still `{ duration: 0 }` while search filters rows — row set churns per keystroke, gliding reads as noise. Ref: `navigator/tables-list.tsx`.
- **Collapse/disclosure**: animate CSS grid rows with motion, not Tailwind transition — `motion.div` `initial={false} animate={{ gridTemplateRows: open ? '1fr' : '0fr' }}` (house curve) wrapping a `min-h-0 overflow-hidden` child. Ref: `TableError` in `-tabs/table/-components/table/table.tsx`.
- **Swapping two panels in one slot**: `AnimatePresence mode="popLayout"` keyed on panel id, `opacity` + small `x` offset in push direction (12px full panel, 6px label inside button), 150–180ms — push and back read as one object moving. Ref: `navigator/navigator.tsx`, `navigator-switcher.tsx`.
- **Reorderable strips**: `Reorder.Group`, `layout="position"` on items, `transition={{ layout: dragging ? houseCurve : { duration: 0 } }}` — animate while dragging, snap otherwise (no drift when labels change width). Value identity rules in gotchas.md.
- Scroll-edge cues: never JS scroll listeners. Plain scrollers use `scroll-fade` (CSS scroll-driven mask, kit utility). Data table uses `table-fade` overlay gradients (mask would clip the scrollbar) — see gotchas.
- **Popup enter/exit** (kit `DropdownMenuContent`/`SubContent`, `ContextMenuContent`, `MenubarContent`/`SubContent`, `SelectContent`, `PopoverContent`, `ComboboxContent`): tw-animate-css `animate-in`/`animate-out` + `fade`/`zoom-95`/`slide-*-2`, timed `data-open:duration-150 data-closed:duration-100 ease-[cubic-bezier(0.32,0.72,0,1)]` — the shared `duration-100` + default `ease` they shipped with read as *no* animation (100ms of a 5% zoom at `ease` is below the noticing threshold). Exits stay shorter than entries. Base-ui `data-instant` (`click` on keyboard activation, `dismiss` on Escape) is deliberately **not** wired to a duration — the animation plays on those paths too.
