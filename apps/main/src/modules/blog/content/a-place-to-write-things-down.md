I never planned to have a blog. The changelog covers what shipped, and most of what I think fits in a tweet. But some things need more room than a tweet and do not belong in a list of version numbers.

So this is that room. Not a content calendar. No posting schedule. I write here when there is something worth a few paragraphs: why a feature works the way it does, a decision I went back and forth on, a story behind a fix.

If you want the short version of what is new, the releases page has it. If you want the reasoning, it ends up here. And if you think I got something wrong, open an issue on GitHub. That is still the best place to argue with me.

More soon, but only when it is worth your time.
